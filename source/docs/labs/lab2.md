### **Создание и обработка массивов**

| Функция | Реализация |
| :---- | :---- |
| create\_vector() | np.arange(10) \- массив \[0..9\] |
| create\_matrix() | np.random.rand(5, 5\) \- матрица 5×5 из равномерного распределения |

| transpose\_matrix(mat) | mat.T \- транспонирование |

**Векторные операции**

| Функция | Реализация |
| :---- | :---- |
| vector\_add(a, b) | a \+ b \- поэлементное сложение |
| scalar\_multiply(vec, scalar) | vec \* scalar \- broadcasting |
| elementwise\_multiply(a, b) | a \* b \- поэлементное умножение |
| dot\_product(a, b) | np.dot(a, b) \- скалярное произведение |

**Матричные операции**

| Функция | Реализация |
| :---- | :---- |
| matrix\_multiply(a, b) | a @ b \- матричное умножение |
| matrix\_determinant(a) | np.linalg.det(a) \- расчет определителя |
| matrix\_inverse(a) | np.linalg.inv(a) \- обратная матрица |
| solve\_linear\_system(a, b) | np.linalg.solve(a, b) \- решение Ax \= b |

**Статистический анализ**

**Визуализация**
