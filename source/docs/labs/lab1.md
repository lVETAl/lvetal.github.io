
# Отчет по лабораторной работе № 1  
## Создание и развертывание статического сайта на базе MkDocs с публикацией на GitHub Pages  

### **Цель работы**  
Освоить процесс создания статического сайта с помощью генератора документации MkDocs. Научиться выстраивать структуру портфолио, применять темы оформления, настраивать навигацию и публиковать сайт через GitHub Pages.  

### **Среда разработки и архитектура**  
- **Язык и инструменты:** Python 3.10+, MkDocs, Git, GitHub, VS Code  
- **Виртуальное окружение:** `venv`  
- **Тема оформления:** Material (обоснование – современный адаптивный дизайн, встроенный поиск, переключение цветовых схем, удобная навигация с вкладками и подсветка кода)  
- **Структура проекта:**  
  ```
  username.github.io/             # корень репозитория
  ├── source/                     # исходные файлы MkDocs
  │   ├── docs/
  │   │   ├── index.md            # главная
  │   │   ├── about.md            # об авторе
  │   │   ├── contact.md          # контакты
  │   │   └── labs/
  │   │       ├── index.md        # обзор лабораторных
  │   │       ├── lab1.md ... lab9.md
  │   ├── skins/images/           # icon и логотип
  │   └── mkdocs.yml             # конфигурация
  ├── docs/                       # сгенерированный сайт (публикация)
  ├── .gitignore
  └── README.md
  ```

### **Выполненные задания**  

#### **Создание и настройка репозитория**  
- Создан публичный репозиторий 
- В разделе Settings → Pages настроена публикация из каталога `/docs` ветки `main`.  
- Репозиторий склонирован локально для дальнейшей работы.  

#### **Локальная подготовка**  
- Инициализировано виртуальное окружение `python -m venv venv` и активировано.  
- Установлен MkDocs: `pip install mkdocs`.  
- В корне репозитория создан файл `.gitignore` для исключения `venv/`, `.vscode/`, `__pycache__/` и временных файлов.  

#### **Инициализация структуры сайта**  
- Выполнена команда `mkdocs new source` – создана базовая структура с каталогом `docs` и файлом `mkdocs.yml`.  
- Локальный предпросмотр запускался через `mkdocs serve` для контроля изменений в реальном времени.  

#### **Настройка конфигурации**  
Файл `mkdocs.yml` полностью настроен. Итоговое содержимое (после устранения дублирования секций, внесённого при редактировании) включает:

- **Название сайта:** `Simina Elisaveta | My portfolio`  
- **Навигация:** меню с пунктами «Главная», «Об авторе», «Контакты» и разделом «Лабораторные работы». Внутри раздела создана страница-обзор (`labs/index.md`) и девять страниц для лабораторных работ: от `labs/lab1.md` до `labs/lab9.md`.  
- **Тема:** `material`  
  - **Иконки:** `icon` и `logo` загружены из `skins/images/`.  
  - **Цветовые схемы:** две палитры (`slate` и `default`) с переключателем, основной цвет `dark blue`, акцент `deep blue`.  
  

#### **Наполнение контентом**  
- **Главная страница** содержит приветствие и краткое описание портфолио.  
- **Об авторе** – личная информация 
- **Обзор лабораторных работ** – страница `labs/index.md` с кратким введением в раздел с отчетами 
- **Страницы лабораторных работ (lab1–lab9)** отчеты к работам в этом семестре
- **Контакты** – блок со ссылками для контактов

#### **Сборка и публикация**  
- Сборка статического сайта выполнялась командой:  
  ```bash
  mkdocs build -d ../docs
  ```  
  В результате все Markdown-файлы преобразованы в HTML, JS и CSS и размещены в корневом каталоге `docs`.  
  

### **Проверка работоспособности**  
- Локально:  запускала сайт без ошибок, все ссылки меню работали, переключение тем выполнялось корректно.  
- Удалённо: опубликованный сайт полностью повторял локальную версию – навигация, фавикон, логотип и цветовые схемы отображались правильно, загрузка страниц происходила быстро.
